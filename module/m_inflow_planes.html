Time-indexed y-z velocity planes for precursor-successor inflow.

A precursor run samples u, v, w on one y-z plane every sample_every iterations and writes them in blocks of ntimesteps planes, one ADIOS2 file per block (Incompact3d append_outflow/write_outflow). A successor reads the blocks back with read_inflow_block and imposes them as a time-varying inflow. The on-disk layout is documented under "Precursor inflow planes" in docs/source/user/input_file.rst; bump INFLOW_FORMAT_VERSION when it changes.

type, public ::  inflow_plane_reader_t

Replays the planes of ninflows files as a time-varying inflow. Plane n (1-based, counted across the files) is the inflow at time n*plane_dt; between planes it is interpolated linearly, and after the last plane the series repeats from the first.

public subroutine read_inflow_block(filename, mesh, u, v, w, times, plane_dt)
